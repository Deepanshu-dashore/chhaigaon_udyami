# Technology Stack

## Core Technologies
- **Framework**: Next.js 16.3.4 (App Router)
- **UI Runtime**: React 19.2.8 & React DOM 19.2.8
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS v4 (`@tailwindcss/postcss`), `clsx`, `tailwind-merge`
- **Icons**: `lucide-react`
- **Database & ORM**: PostgreSQL via Supabase, Prisma ORM 7.10.0 with `@prisma/adapter-pg`
- **Authentication**: `@supabase/supabase-js` 2.116.0, `@supabase/ssr` 0.12.7
- **Video Delivery**: VdoCipher encrypted streaming iframe embed
- **Payment Gateway**: Razorpay REST API
